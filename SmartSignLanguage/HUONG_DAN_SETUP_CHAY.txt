VIRTUAL ENVIRONMENT (venv):
===========================

✗ LỖI: "venv\Scripts\activate.bat" không tìm thấy
  ✓ GIẢI PHÁP: Tạo venv lại
    > python -m venv venv
    > venv\Scripts\activate.bat

✗ LỖI: "(venv)" không hiển thị trong command prompt
  ✓ GIẢI PHÁP: venv chưa được kích hoạt
    > venv\Scripts\activate.bat
    (hoặc dùng script start-dev.bat)

✗ LỖI: "Python not found"
  ✓ GIẢI PHÁP: Cài Python từ https://www.python.org/
    Chọn: Python 3.10+ (LTS)
    Khi cài: ✓ Check "Add Python to PATH"

✗ LỖI: Deactivate không hoạt động
  ✓ GIẢI PHÁP: Gõ lệnh chính xác:
    > deactivate
    (không có dấu / backslash)

NODE.JS & NPM:
==============

✗ LỖI: "npm: not found" hoặc "node: not found"
  ✓ GIẢI PHÁP: Cài đặt Node.js từ https://nodejs.org/
     Chọn LTS version
     Sau cài phải khởi động lại Command Prompt

✗ LỖI: "ERR! EACCES: permission denied"
  ✓ GIẢI PHÁP: 
    Cách 1: Chạy Command Prompt as Administrator
    Cách 2: npm config set prefix "C:\npm" --global

✗ LỖI: "Port 8080 already in use"
  ✓ GIẢI PHÁP: Tìm process dùng port 8080
    > netstat -ano | findstr :8080
    Hoặc đổi cổng trong vite.config.ts

✗ LỖI: "Cannot find module" hoặc "Missing dependencies"
  ✓ GIẢI PHÁP: Xóa node_modules và reinstall
    > rmdir node_modules /s /q
    > npm install

PROJECT:
========

✗ LỖI: "Database error" khi chạy dev
  ✓ GIẢI PHÁP: Xóa folder data/ và chạy lại
    > rmdir data /s /q
    > npm run dev
    Database sẽ tự động được tạo lại

✗ LỖI: Dung lượng C ổ đầy (node_modules quá lớn)
  ✓ GIẢI PHÁP: Dùng venv (đã setup sẵn)
    Hoặc:
    > rmdir node_modules /s /q

PHẦN 8: TIPS & TRICKS - VIRTUAL ENVIRONMENT
================================================================================

1. HỎI: Folder venv là gì?
   ĐÁP: Là Virtual Environment của Python - chứa tất cả npm packages
        Nó cho phép project có environment riêng, không ảnh hưởng đến hệ thống

2. HỎI: Tại sao cần kích hoạt venv?
   ĐÁP: Để npm packages được cài trong venv, không tốn ổ C chính

3. HỎI: Mỗi lần chạy đều phải kích hoạt venv?
   ĐÁP: Có, hoặc dùng script start-dev.bat/sh để tự động

4. HỎI: Xóa venv được không?
   ĐÁP: Được! Chỉ cần:
        > rmdir venv /s /q    (Windows)
        $ rm -rf venv          (MacOS/Linux)
        Sau đó tạo lại bằng: python -m venv venv

5. HỎI: Node_modules ở đâu?
   ĐÁP: Trong thư mục project hiện tại (E:\...\SmartSignLanguage\node_modules)
        Được cài khi npm install trong venv
        Dung lượng: ~500MB

6. CHROME DEVTOOLS DEBUG:
   - Chạy: npm run dev
   - Mở DevTools: F12
   - Network tab: xem API calls
   - Console tab: xem errors

7. THEME & STYLING:
   - Mở: client/global.css
   - Edit Tailwind config: tailwind.config.ts
   - Tự động hot-reload trên browser

8. THÊM PAGE MỚI:
   - Tạo: client/pages/MyPage.tsx
   - Thêm route trong App.tsx:
     <Route path="/my-page" element={<MyPage />} />

9. THÊM API ENDPOINT:
   - Tạo: server/routes/my-route.ts
   - Đăng ký trong: server/index.ts
     app.get("/api/my-endpoint", handleMyRoute);

10. MULTIPLE TERMINALS:
    Terminal 1: npm run dev  (Dev server)
    Terminal 2: npm test     (Tests)
    
    Mỗi terminal cần kích hoạt venv riêng!
